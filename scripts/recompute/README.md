These scripts rematch donors to `lake.nppes_full` on the **hhs_doge** Postgres instance.
They are archived here so the method left `hhs_doge`. They are not needed to read the analysis.

To rematch: run them with `hhs_doge` on `PYTHONPATH` and a working `src.db` connection.
Output paths inside the scripts still mention `hhs_doge/outputs/...` until edited.
